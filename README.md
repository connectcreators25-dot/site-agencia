# Vertex Labs — Site da Agência

Site institucional da Vertex Labs.

## Estrutura
- `index.html` — página principal
- `css/styles.css` — estilos
- `js/main.js` — interações
- `assets/brand/` — logo
- `assets/projects/` — prints dos projetos

## Deploy
Abra no Vercel/Netlify apontando para a raiz do repositório.

Faça upload da pasta `assets/` (brand + projects) para as imagens aparecerem no portfolio.
